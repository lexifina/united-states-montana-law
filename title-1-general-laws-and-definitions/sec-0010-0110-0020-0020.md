# 1-11-202. Qualifications of code commissioner.
To be eligible to be code commissioner, a person must be licensed to practice law in Montana for at least 5 years and demonstrate a knowledge of code arranging and recodification procedures.
History: En. 12-503 by Sec. 3, Ch. 419, L. 1975; R.C.M. 1947, 12-503.
