# 46-13-402. Effect of order to dismiss.
If the court directs the action to be dismissed, the defendant must, if in custody, be discharged and, if admitted to bail, have bail exonerated or money deposited instead of bail refunded to the defendant.
History: En. 95-1706 by Sec. 1, Ch. 196, L. 1967; amd. Sec. 23, Ch. 184, L. 1977; R.C.M. 1947, 95-1706(2); amd. Sec. 179, Ch. 800, L. 1991; Sec. 46-13-106, MCA 1989; redes. 46-13-402 by Code Commissioner, 1991.
