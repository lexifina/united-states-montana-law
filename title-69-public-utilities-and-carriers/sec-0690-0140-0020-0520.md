# 69-14-252. Accident reports.
(1) A railroad company operating any line of railroad within this state shall promptly on the occurrence of an accident report the accident to the commission. The report must include the time and place of the accident, the names of any persons killed or injured, and the value of any property destroyed.
(2) The commission may adopt rules to set reporting thresholds and implement this section.
