# 27-17-402. Duty to return property in good condition.
In all cases when a judgment is rendered, in an action to recover the possession of personal property, for the return of personal property or its value if a return cannot be had, it is the duty of the party against whom the judgment is rendered to return the property in as good condition as the property was when possession was taken by the party.
