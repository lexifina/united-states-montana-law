# 27-17-202. Description of property in affidavit.
Where the affidavit describes two or more chattels of the same kind, it must state the number thereof, and where it describes a chattel in bulk, it must state the weight, measurement, or other quantity, as nearly as can be ascertained. Where it describes two or more chattels, it may, at the election of the plaintiff, state the aggregate value of all or, separately, the value of any chattel or of any class of chattels and the aggregate value of the remainder, if any.
History: En. Sec. 856, C. Civ. Proc. 1895; re-en. Sec. 6638, Rev. C. 1907; re-en. Sec. 9236, R.C.M. 1921; re-en. Sec. 9236, R.C.M. 1935; R.C.M. 1947, 93-4117(part).
