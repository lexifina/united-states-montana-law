# 27-1-304. Value of written instrument.
For the purpose of estimating damages, the value of an instrument in writing is presumed to be equal to that of the property to which it entitles the owner.
History: En. Sec. 4363, Civ. C. 1895; re-en. Sec. 6084, Rev. C. 1907; re-en. Sec. 8702, R.C.M. 1921; Cal. Civ. C. Sec. 3356; Based on Field. Civ. C. Sec. 1875; re-en. Sec. 8702, R.C.M. 1935; R.C.M. 1947, 17-604.
