# 16-2-106. Sales by agent.
A liquor store agent may sell to any person any liquor and table wine that the person is entitled to purchase in conformity with the provisions of this code and the rules implementing this code. An agent may, under the terms and conditions that the agent establishes, deliver liquor and table wine purchased from the agent's agency liquor store. An agent may sell liquor through curbside pickup in original packaging.
