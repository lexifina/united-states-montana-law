# 61-3-573. Gross vehicle weight permanent registration fee -- electric vehicles -- plug-in hybrid electric vehicles.
(1) The permanent registration fee for an electric vehicle is based on unladen gross weight as follows:
(a) for a class 1 vehicle, $260;
(b) for a class 2 vehicle, $380.
(2) The permanent registration fee for a plug-in hybrid electric vehicle is based on gross vehicle weight as follows:
(a) for a class 1 vehicle, $140;
(b) for a class 2 vehicle, $200.
History: En. Sec. 1, Ch. 562, L. 2023; amd. sec. 4, Ch. 562, L. 2023.
