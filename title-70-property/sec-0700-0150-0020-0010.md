# 70-15-201. Application of classifications.
The names and classification of interests in real property have only such application to interests in personal property as is in this code expressly provided.
History: En. Sec. 1123, Civ. C. 1895; re-en. Sec. 4456, Rev. C. 1907; re-en. Sec. 6698, R.C.M. 1921; Cal. Civ. C. Sec. 702; Field Civ. C. Sec. 194; re-en. Sec. 6698, R.C.M. 1935; R.C.M. 1947, 67-328.
