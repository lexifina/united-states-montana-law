# 70-6-106. Deposit for keeping defined.
A deposit for keeping is one in which the depositary is bound to return the identical thing deposited.
History: En. Sec. 2444, Civ. C. 1895; re-en. Sec. 5137, Rev. C. 1907; re-en. Sec. 7640, R.C.M. 1921; Cal. Civ. C. Sec. 1817; Field Civ. C. Sec. 911; re-en. Sec. 7640, R.C.M. 1935; R.C.M. 1947, 20-105.
