# 70-27-116. Verification of complaint and answer.
The complaint and answer must be verified. If new matter be set up in the answer, it is deemed denied.
History: En. Sec. 2095, C. Civ. Proc. 1895; re-en. Sec. 7284, Rev. C. 1907; re-en. Sec. 9902, R.C.M. 1921; Cal. C. Civ. Proc. Sec. 1175; re-en. Sec. 9902, R.C.M. 1935; R.C.M. 1947, 93-9716.
