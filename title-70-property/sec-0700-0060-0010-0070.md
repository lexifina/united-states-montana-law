# 70-6-107. Deposit for exchange defined.
A deposit for exchange is one in which the depositary is only bound to return a thing corresponding in kind to that which is deposited.
History: En. Sec. 2445, Civ. C. 1895; re-en. Sec. 5138, Rev. C. 1907; re-en. Sec. 7641, R.C.M. 1921; Cal. Civ. C. Sec. 1818; Field Civ. C. Sec. 912; re-en. Sec. 7641, R.C.M. 1935; R.C.M. 1947, 20-106.
