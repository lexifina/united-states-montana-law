# 22-1-225. Montana state library trust -- interest retention.
(1) There is an account in the governmental fund category state special revenue fund type to be known as the Montana state library trust, to be used as provided in 22-1-226.
(2) Interest and earnings of the account must be retained by the account.
History: En. Sec. 1, Ch. 339, L. 1995; amd. Sec. 15, Ch. 34, L. 2001.
