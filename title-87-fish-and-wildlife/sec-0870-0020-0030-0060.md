# 87-2-306. Paddlefish tags.
The department may issue paddlefish tags to holders of valid Class A, Class A-8, Class B, Class B-4, and Class B-5 fishing licenses for a fee of $6.50 for residents and $15 for nonresidents. Each tag authorizes the holder to fish with hook and line for paddlefish as prescribed by rules of the department.
