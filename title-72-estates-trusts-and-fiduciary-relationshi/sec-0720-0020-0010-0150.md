# 72-2-115. No taker.
If there is no taker under the provisions of this chapter, the intestate estate passes to the state of Montana.
History: En. 91A-2-105 by Sec. 1, Ch. 365, L. 1974; R.C.M. 1947, 91A-2-105; amd. Sec. 16, Ch. 494, L. 1993; Sec. 72-2-207, MCA 1991; redes. 72-2-115 by Code Commissioner, 1993.
