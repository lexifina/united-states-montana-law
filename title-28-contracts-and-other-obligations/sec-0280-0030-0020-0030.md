# 28-3-203. When several contracts taken together.
Several contracts relating to the same matters, between the same parties, and made as parts of substantially one transaction are to be taken together.
History: En. Sec. 2207, Civ. C. 1895; re-en. Sec. 5031, Rev. C. 1907; re-en. Sec. 7533, R.C.M. 1921; Cal. Civ. C. Sec. 1642; Field Civ. C. Sec. 807; re-en. Sec. 7533, R.C.M. 1935; R.C.M. 1947, 13-708.
