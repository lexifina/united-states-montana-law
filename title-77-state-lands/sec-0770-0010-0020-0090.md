# 77-1-209. Leasing rules.
The board may prescribe rules relating to the leasing of state lands as it considers necessary in order that the use and proceeds of these lands may contribute in the highest attainable measure to the purposes for which they are granted to the state of Montana. The rules should prescribe a procedure for setting all fees and rental rates for the use of state lands for any purpose. The procedure should establish provisions for notice, public comment, public hearings, and appeal.
