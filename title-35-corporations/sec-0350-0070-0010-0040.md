# 35-7-104. Addresses in filings.
Whenever a provision of this chapter other than 35-7-111(1)(d) requires that a filing state an address, the filing must state:
(1) an actual street address or rural route box number in this state; and
(2) a mailing address in this state, if different from the address under subsection (1).
History: En. Sec. 4, Ch. 240, L. 2007.
