# 32-3-602. Loan application.
Every application for a loan must be made upon a form prescribed by the credit union. The application must state the security, if any, offered. Each loan must be evidenced by a written document or electronic data capable of being converted into written form.
History: En. 14-649 by Sec. 49, Ch. 38, L. 1975; R.C.M. 1947, 14-649; amd. Sec. 5, Ch. 25, L. 2001; amd. Sec. 33, Ch. 237, L. 2003.
